# Counterexamples (synthetic, hand-written)

These small files exercise validation and interpretation rules. Each one is generated by
`calibcheck.synthetic.write_counterexamples()`. The expected behaviour is described rather than
given as exact numbers.

| File | Command | Expected behaviour |
|---|---|---|
| `missing_outcomes.csv` | `calibcheck inspect missing_outcomes.csv --prob p_model --id row_id` | Fails with `LABEL_MISSING`. With `--drop-invalid`, the row is excluded, counted and reported. |
| `invalid_probabilities.csv` | `calibcheck inspect invalid_probabilities.csv --prob p_model --id row_id` | Fails with `PROB_OUT_OF_RANGE` and `PROB_NONFINITE`. Nothing is clipped or repaired silently. |
| `percent_scale.csv` | `calibcheck inspect percent_scale.csv --prob p_model --id row_id` | Fails and suggests the explicit `--transform p_model=percent`. Values are never divided by 100 automatically. |
| `single_class.csv` | `calibcheck report single_class.csv --prob p_model --id row_id` | Valid. Brier and log loss are reported. ROC-AUC and average precision are `unavailable (UNAVAILABLE_SINGLE_CLASS)`, and the skill score is undefined. |
| `duplicate_ids.csv` | `calibcheck inspect duplicate_ids.csv --prob p_model --id row_id` | Fails with `ID_DUPLICATE`. Duplicates are never dropped automatically. |
| `multiclass.csv` | `calibcheck inspect multiclass.csv --prob p_model --id row_id --positive-label a` | Fails with `LABEL_NOT_BINARY` (multiclass is on the roadmap). |
| `boundary_and_ties.csv` | `calibcheck report boundary_and_ties.csv --prob p_model --id row_id --strategy quantile` | Exact 0, 1 and edge values are assigned once each. Quantile bins collapse on ties, and the actual bin count is reported. |
| `yes_no_labels.csv` | `calibcheck inspect yes_no_labels.csv --label outcome --prob p_yes --id row_id` | Fails until `--positive-label yes` is given. The probability then means P(outcome = 'yes'). |

The synthetic scenarios in `calibcheck.synthetic` cover the larger counterexamples: strong
ranking with poor calibration, a constant prevalence forecast, near-calibrated models where
recalibration may not help, tiny samples, subgroup gaps that cancel in aggregate, and
dependence-marked data. Each scenario carries an `expected_interpretation` string, and
`tests/integration/test_scenarios.py` checks those interpretations.

# Code of Conduct

This project follows the spirit of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**Expected:** being respectful and constructive, assuming good faith, giving feedback about
code and methods rather than people, and crediting others' work.

**Unacceptable:** harassment, personal attacks, discriminatory language, publishing others'
private information, and sharing anyone's private datasets without consent.

**Scope:** project spaces (issues, pull requests, discussions) and public representation of the
project.

**Enforcement:** report concerns privately to the maintainers at the contact address listed in the
repository profile. Maintainers may remove content, warn, or block participants. Reports are
handled confidentially.
